# Naaz World | Premium E-Commerce Platform

Naaz World is a modern, high-performance e-commerce marketplace built for the Bangladesh market. It features a premium UI/UX design, real-time cart management, and a robust architecture designed for scalability.

## 🚀 Key Features

* **Premium UI:** Glassmorphism-inspired design with neon accents and smooth interactivity.
* **Performance-First:** Built with Next.js 16+ for lightning-fast page loads and SEO optimization.
* **Inventory Management:** Real-time stock tracking and category-based filtering.
* **Responsive Design:** Fully optimized for mobile-first shopping experiences.
* **Secure API:** Integrated with a Node.js/Express backend and MongoDB for data integrity.

## 🛠️ Tech Stack

* **Frontend:** Next.js (App Router), Tailwind CSS (v4)
* **Backend:** Express.js, Node.js
* **Database:** MongoDB (Atlas)
* **State Management:** React Context API
* **Deployment:** Vercel (Production) / Hostinger (DNS Management)

## 📂 Project Structure


/src
  /app           # Next.js App Router (Pages & API routes)
  /components    # UI Components (ProductCard, Navbar, Footer, Hero)
  /context       # Global State Management (CartContext)
  /styles        # Global Tailwind/CSS styles
/api             # Express backend logic
```
